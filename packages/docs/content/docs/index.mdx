## What you can do [#what-you-can-do]

- Search hotels in a city, region or country, near a place or point, or by name or brand. See [How search works](/search).
- Read a hotel's details: address, check-in times, description, policies, amenities and room types.
- Get live offers for up to <Fact path="LIMITS.offersHotels" /> hotels: the room, the meals, the total, fees payable at the property and the cancellation terms.
- Order an offer and have the user pay it; then follow the order, cancel it under its terms, and list past orders. See [Orders and payment](/payments#flow).

Flights, activities and changes to existing orders aren't supported.

## Key terms [#key-terms]

- **Offer**: a live, bookable room at a total price, with its terms. A search's **indicative price** only shows roughly what a hotel costs; it can't be booked.
- **Order**: what ordering an offer creates. Nothing is charged until the user pays.
- **Payment link**: the order's `payment.url`, a Fortrip page where the user pays.
- **Link token**: a shared payment token from the user's Stripe Link wallet. Some agents can pay an order with one, once the user approves it.
- **Reference**: the order's number, starting `FT-`. The user quotes it to support.

## Ways to connect [#ways-to-connect]

Fortrip connects as an [agent skill](/install#skill), a [CLI](/install#cli), a [remote MCP server](/install#remote-mcp), a [local MCP server](/install#local-mcp) or the [HTTP API](/api). Each signs in with a Fortrip account and returns the same data.
