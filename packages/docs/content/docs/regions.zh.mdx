## “已启用”的含义 [#what-it-means]

- 已启用地区的名称会解析为该地区，搜索覆盖其中的所有酒店。只有当酒店所在地区已启用时，酒店的 `address.region` 才会写出该地区；否则为 `null`。
- 在其他地方，地区名称不会作为地区匹配，所以它可能匹配到同名的城镇或岛屿。参见[区域与半径](/search#scopes)。
- 列表中地区的 `placeId` 会一直可以解析。
