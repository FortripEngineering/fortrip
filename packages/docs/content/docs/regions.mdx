Not listed? Search a town, a point or the country.

## What enabled means [#what-it-means]

- An enabled region's name resolves to the region, and a search covers every hotel in it. A hotel's `address.region` names its region only when the region is enabled; otherwise it is `null`.
- A region is listed only where Fortrip can place its hotels reliably. Regions in mainland China are enabled.
- Elsewhere, a region's name isn't matched as a region, so it can match a town or island of that name. See [areas and radii](/search#scopes).
- The list changes only with a reviewed release. A region on it stays on it unless Fortrip decides otherwise, and its `placeId` keeps resolving.
