The exceptions: `fortrip mcp` speaks MCP over stdin and stdout, and `--help` and `--version` print plain text.

## Install [#install]

```sh
npm install -g fortrip
```

Or run any command with `npx fortrip`. Needs Node.js <Fact path="CLI_NODE_MAJOR" /> or newer. Sign in with [`fortrip login`](/cli/login).

## A booking by hand [#walkthrough]

Each answer is compact text with the ids the next command takes.

```sh
npx fortrip hotels search --place-name Kyoto --country JP --check-in YYYY-MM-DD --check-out YYYY-MM-DD --room 2
npx fortrip hotels offers --hotel htl_… --check-in YYYY-MM-DD --check-out YYYY-MM-DD --room 2 --require-free-cancellation
npx fortrip orders create --offer off_… --guest 1:First:Last --name "First Last" --email you@example.com --phone +1…
npx fortrip orders get ord_…
```

`--room 2` is one room for two adults; `--guest 1:First:Last` is a guest in room 1, named as on the passport. `orders create` creates an unpaid order, and `orders get` prints its payment link: nothing is charged until you pay on it.

## Updates [#updates]

Keep the CLI on the service's major version: `npm install -g fortrip@latest`, or run it as `npx -y fortrip@latest`. A CLI that is a major version behind is refused with [`client_outdated`](/errors#code-client_outdated).
