---

The exceptions: `fortrip mcp` speaks MCP over stdin and stdout, and `--help` and `--version` print plain text.

## Install [#install]

```sh
npm install -g fortrip
```

Or run any command with `npx fortrip`. Needs Node.js <Fact path="CLI_NODE_MAJOR" /> or newer. Sign in once with [`fortrip login`](/cli/login); you stay signed in until `fortrip logout`. See [Installation](/install#cli).

## Raw request body [#raw-body]

`hotels search`, `hotels offers` and `orders create` also take `--body` with a JSON object, or `--body @file.json`. Flags override its fields. Field names and limits are the same as the [MCP tool inputs](/mcp) and the [HTTP API](/api) bodies.
