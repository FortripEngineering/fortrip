
## 比价保障 [#price-match]

当用户说在其他网站看到同一住处更便宜时，发送该报价的 `offerId` 和那个网站的名称。向用户要看到该价格的页面链接，作为 `link` 发送：核查会从这个页面开始，比价网站上跳转到预订网站的链接也算数。没有链接也会照常核查。如果用户给了看到的总价，也一并发送。Fortrip 随后只核查这一个网站，最长可能需要十分钟，所以响应会立即返回，带一个 `claimId` 和 `state: "checking"`；如果没有启动核查，请求也可能被立即拒绝，此时带 `reason`，没有 `claimId`。这不是保证：只核查指定的网站，或链接跳转到的预订网站，结果也可能是目前没有可匹配的价格。如果报价生成后 Fortrip 自己的房价变了，请求会返回 [`offer_expired`](/errors#code-offer_expired)：重新获取报价，再针对新报价申请比价。
