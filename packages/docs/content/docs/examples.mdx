Every example sends the same request in all three languages. Run one with `FORTRIP_TOKEN` set to a Fortrip access token. The ids are placeholders: use the ones the previous answer gave you. The TypeScript examples use `fetch` on Node.js, and the Python examples use [`httpx`](https://www.python-httpx.org/).
