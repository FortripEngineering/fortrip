Every call sends `FORTRIP_TOKEN`, an access token of the user who signs in. There is no test environment: searching, getting offers and creating an order are free, an unpaid order expires on its own, and any payment is real. See [Testing your integration](/faq#testing).

The TypeScript examples use `fetch` on Node.js, and the Python examples use [`httpx`](https://www.python-httpx.org/).

## End to end in five steps [#end-to-end]

You need curl and jq. Each call saves its answer to a file, and the next call takes its id from that file.

## Cancel [#cancel]

The order's `cancel.action` says which request applies. `cancel`: a paid order, cancelled with `maximumPenalty` set to the order's `cancel.penalty` that the user agreed to, exactly as returned. `close`: an unpaid order, closed with `close: true` in place of `maximumPenalty`, once the user says they no longer want it. Send exactly one of the two; `null` means neither applies, and `cancel.blockedBy` says why. See [Cancel or close](/payments#cancel).
