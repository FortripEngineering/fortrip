Every call sends `FORTRIP_TOKEN`, an access token of the user who signs in. There is no test environment: any payment is real. See [Testing your integration](/faq#testing).

The TypeScript examples use `fetch` on Node.js, and the Python examples use [`httpx`](https://www.python-httpx.org/).

## End to end in five steps [#end-to-end]

You need curl and jq. Each call saves its answer to a file, and the next call takes its id from that file.

## Price match [#price-match]

When the user says they saw an offer's stay cheaper on another site, send the offer's `offerId` and that site's name, with the link or the total they saw if they gave one. Fortrip then checks that one site, which can take up to ten minutes, so the answer comes at once with a `claimId` and `state: "checking"`. It is not a guarantee: only the site named is checked, and the result can be that no match is available right now.
