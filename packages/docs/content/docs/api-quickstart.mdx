Every call sends `FORTRIP_TOKEN`, an access token of the user who signs in. The examples are files that are checked against the contract. The TypeScript examples use `fetch` on Node.js, and the Python examples use [`httpx`](https://www.python-httpx.org/).

## End to end in five calls [#end-to-end]

You need curl and jq. Each call saves its answer to a file, and the next call takes its id from that file.

### Refresh a token [#refresh]

The access token is short-lived. Get a new one with the refresh token, at the same token endpoint. Each refresh also returns a new refresh token: keep only the newest, because reusing an old one signs the user out.

## Order [#order]

Ordering charges nothing. Show the user the total and every term, and wait for a clear yes before anyone pays. The order can take a couple of minutes; if the call times out, send the same body again and you get the same order. See [Orders and payment](/payments).
