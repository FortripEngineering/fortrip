Every call sends `FORTRIP_TOKEN`: your [API key](/api#api-keys), or an access token from [signing in](#sign-in). There is no test environment: any payment is real. See [Testing your integration](/faq#testing).

The TypeScript examples use `fetch` on Node.js, and the Python examples use [`httpx`](https://www.python-httpx.org/).

## End to end in five steps [#end-to-end]

You need curl and jq. Each call saves its answer to a file, and the next call takes its id from that file.

## Sign in without a key [#sign-in]

Until you have an API key, sign in instead. This script runs the OAuth device flow and prints the access token and the refresh token: set `FORTRIP_TOKEN` to the access token. [Authentication](/api#authentication) explains the flow and when to use another.

<Example name="device-login" />

In curl, save the script as `device-login.sh` and keep its output in `token.json`, which [Refresh a token](#refresh) reads:

```sh
umask 077 # token.json is readable by you only
bash device-login.sh > token.json
export FORTRIP_TOKEN=$(jq -r .access_token token.json)
```

## Price match [#price-match]

When the user says they saw an offer's stay cheaper on another site, send the offer's `offerId` and that site's name. Ask the user for the link to the page where they saw the price and send it as `link`: the check starts from that page, and a link on a comparison site that leads to the booking site counts. Without a link the check still runs. Send the total they saw if they gave one. Fortrip then checks that one site, which can take up to ten minutes, so the answer comes at once with a `claimId` and `state: "checking"`; a request can also be declined at once, with a `reason` and no `claimId`, when no check is started. It is not a guarantee: only the site named, or the booking site the link leads to, is checked, and the result can be that no match is available right now. If Fortrip's own price for the room changed since the offer was made, the request answers [`offer_expired`](/errors#code-offer_expired): get offers again and ask for a price match on the new offer.
